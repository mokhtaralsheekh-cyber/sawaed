تطبيق منظومة سواعد الغد الحديثة (PWA)

الملفات: index.html (التطبيق) - manifest.json - sw.js (العمل بدون إنترنت) - icon-192.png - icon-512.png
ارفع كل الملفات معًا في نفس المجلد.

النشر (مجاني، ويلزم رابط https):
1) Netlify: ادخل app.netlify.com/drop واسحب المجلد كاملًا، فيعطيك رابطًا.
2) أو GitHub Pages: ارفع الملفات إلى مستودع وفعّل Pages من الإعدادات.

التثبيت على الهاتف:
افتح الرابط في Chrome، ثم اضغط زر "تثبيت التطبيق" داخل الصفحة،
أو قائمة المتصفح (⋮) ثم "تثبيت التطبيق" / "إضافة إلى الشاشة الرئيسية".

ملاحظات:
- البيانات تُحفظ في متصفح الجهاز فقط، ولا تنتقل بين الأجهزة.
- بعد أول فتح بالإنترنت يعمل التطبيق بدون إنترنت. تحميل مكتبة PDF يحتاج إنترنت مرة واحدة،
  ويمكن دائمًا استخدام الطباعة ثم "حفظ كـ PDF".
- زر "إضافة فاتورة بصورة" يطلب مفتاح Gemini API أول مرة (من aistudio.google.com) ويحفظه على جهازك.
